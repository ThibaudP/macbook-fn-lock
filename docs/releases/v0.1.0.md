MacBook Fn Lock brings a double-tap Fn gesture and a compact GNOME panel indicator to MacBooks running Linux.

- Switch between **Multimedia mode** and **F1-F12 mode** with two Fn taps or the menu's **Fn Lock** switch.
- A blue icon indicates F1–F12 mode; the menu stays open when changing modes.
- The selected mode is restored after reboot.
- Ordinary Fn combinations keep their usual behavior.

Compatibility: **GNOME Shell 51**, including Wayland; an Apple keyboard using **`hid_apple`** and exposing **`KEY_FN`**. Checked on MacBookPro10,2 with Ubuntu 26.10. Other GNOME versions and keyboard drivers are not supported by this release.

### Install

Download and extract **macbook-fn-lock-0.1.0.tar.gz**, then run as your desktop user:

```sh
cd macbook-fn-lock-0.1.0
./install.sh
```

The installer uses sudo for the required system service. Follow the README to activate or reload the extension in your current GNOME session. The **extension ZIP alone does not install the service**.

Verify downloads with `sha256sum -c SHA256SUMS` from the directory containing both archives. Remove the installation with `./uninstall.sh` from the extracted source directory.
